# assets

| 폴더 | 쓰는 곳 | 경로 설정 파일 |
|---|---|---|
| `images/wallpaper/` | 잠금 화면(`lock`), 홈 화면(`home`) 배경 | `data/config.js` |
| `images/news/` | Safari 뉴스 기사 사진 | `data/web.js` |
| `images/twitter/` | 트윗 첨부 이미지 (프로필 사진은 `users[].avatar`로 추가 가능) | `data/twitter.js` |
| `images/messages/` | 메시지 속 사진 | `data/messages.js` |
| `images/notes/` | 메모 사진 | `data/notes.js` |
| `images/music/` | 앨범 커버, `what-a-lovely-world-we-share.jpg`를 넣으면 됩니다 | `data/music.js` |
| `audio/` | 음원, `what-a-lovely-world-we-share.mp3` (연결됨) | `data/music.js` |

지금 들어 있는 `.svg` 파일은 모두 임시 그림입니다. 같은 이름의 파일로 덮어쓰거나 데이터 파일의 경로를 바꿔 주세요.
배경화면은 세로 1179×2556(iPhone 15 Pro 해상도)을 권장합니다.

개인정보 안내

대상: 이 사이트의 트위터 화면에 있는 방문자 글쓰기 기능 · 상태: 초안이며 법률 검토를 받지 않았습니다 · 시행일 미정

휴대폰 화면 속 인물, 메시지, 게시물(세계관 콘텐츠)은 지어낸 이야기입니다. 이 안내는 실제 방문자가 쓰는 글과 그 처리 과정에 관한 것입니다. 미정으로 표시된 항목은 운영자가 아직 정하지 않은 내용입니다.

1. 처리하는 정보와 목적, 보유 기간

글쓰기에 입력받는 정보는 공개용 닉네임과 본문뿐입니다. 실명, 이메일, 전화번호, 생년월일, 주소, 위치, SNS 계정은 묻지 않습니다. 다만 본문에 무엇을 적을지는 작성자가 정하므로, 본인이나 다른 사람의 개인정보가 적힐 수 있습니다. 이 사이트는 그런 내용을 자동으로 걸러 내지 않습니다.

정보목적보유·파기
닉네임, 본문 (누구나 볼 수 있음)글을 게시하고 보여 주기작성자나 운영자가 삭제하면 운영 DB에서 바로 지웁니다. 삭제하지 않은 글의 보유 기간은 미정이며, 현재는 기한을 두지 않았습니다.
작성 시각, 답글 관계(어느 글에 단 답글인지)정렬, 답글 연결글과 같습니다. 아래 '삭제 표시'도 참고하세요.
방문자 핸들 @v_xxxxxxxx (누구나 볼 수 있음)같은 닉네임을 쓰는 다른 작성자와 구분하기무작위로 만듭니다. 그 방문자의 글이 하나라도 남아 있는 동안 보관합니다.
방문자 토큰의 HMAC 값 (서버)본인 글만 삭제할 수 있게 확인하기토큰 원문은 서버에 저장하지 않습니다. 남은 글이 없는 방문자 정보는 약 1시간 뒤 자동으로 지웁니다. '내 글 모두 삭제'를 누르면 바로 지웁니다.
중복 방지 키 (작성할 때마다 만드는 무작위 값)다시 시도할 때 같은 글이 두 번 저장되지 않게 하기글을 삭제하면 함께 지웁니다.
IP 주소도배·스팸 제한요청을 처리하는 동안에만 쓰고, 원문은 DB나 앱 로그에 저장하지 않습니다. 대신 'IP + 날짜(UTC)'로 만든 HMAC 값을 글·방문자 정보와 연결하지 않은 별도 기록에 남기고, 1시간이 지나면 지웁니다. 정리 작업은 10분마다 실행되므로 실제로는 최대 약 70분까지 남을 수 있습니다. 날짜가 바뀌면 값도 바뀌므로 다른 날의 방문과는 비교할 수 없습니다. 다만 서버의 비밀 키로 같은 날의 같은 IP인지는 확인할 수 있으므로, 이 값도 개인정보로 다룹니다.

삭제 표시: 다른 사람의 답글이 달린 글을 삭제하면 닉네임, 본문, 작성자 연결을 지우고 글 번호, 작성·삭제 시각, 답글 관계만 남깁니다. 화면에는 "삭제된 게시물입니다."로 나옵니다. 다른 사람의 답글은 함께 지우지 않으며, 그 아래 답글이 모두 없어지면 삭제 표시도 자동으로 지워집니다.

운영자의 숨김: 운영자가 문제 있는 글을 '숨김' 처리하면 화면에서만 사라지고 내용은 DB에 남습니다. 작성자가 직접 삭제하거나 운영자가 삭제하면 내용을 지웁니다.

이용 제한: 같은 방문자는 15초에 1개, 1시간에 30개까지 쓸 수 있습니다. 같은 IP에서는 1시간에 글 40개, 새 방문자 등록 10개까지 가능합니다.

2. 브라우저에 저장되는 정보

쿠키는 쓰지 않습니다. 대신 브라우저의 localStorage에 아래 정보를 저장합니다.

이름내용서버로 보내는 경우
wphone.tw.session방문자 토큰과 핸들. 본인 글을 삭제할 수 있는 권한입니다.글을 쓰거나 지우거나 목록을 불러올 때, 본인 글을 표시하려고 요청 헤더에 넣어 보냅니다.
wphone.tw.nick마지막으로 쓴 닉네임 (다음 글쓰기 칸에 미리 채움)글을 쓸 때만 보냅니다.
wphone.tw.likes, wphone.notes.v1, wphone.msg.read, wphone.music.*좋아요 표시, 메모 편집, 읽음 표시, 음악 설정보내지 않습니다. 이 브라우저에만 있습니다.

글쓰기 화면의 내 글 모두 삭제를 누르면 서버의 내 글과 방문자 정보를 지운 뒤, 이 브라우저의 wphone.tw.session과 wphone.tw.nick도 지웁니다. 다음에 글을 쓰면 새 방문자로 시작합니다. 브라우저의 사이트 데이터를 먼저 지우면 토큰이 사라져 기존 글을 직접 삭제할 수 없게 되니, 필요하면 먼저 글을 삭제하세요.

3. 쓰지 않는 것

이 사이트의 코드에는 광고·분석 도구, 방문자 추적, 브라우저 지문 수집이 없고, 위치·연락처·카메라·마이크 권한도 요청하지 않습니다. 방문자 토큰은 이 사이트 안에서 본인 글을 확인하는 데만 쓰고, 다른 사이트의 활동이나 실제 신원과 연결하지 않습니다.

아래 4번의 서비스들은 자체 정책에 따라 접속 정보를 기록할 수 있습니다. 이 기록은 이 사이트의 코드가 수집하는 정보와 별개입니다.

4. 이용하는 외부 서비스와 국외 처리

이 사이트는 아래 서비스에서 운영되며, 정보가 국외에서 처리·보관됩니다. 각 서비스의 내용은 공식 문서를 기준으로 적었습니다.

서비스 (회사)하는 일거치는 정보위치·서비스 측 기록
GitHub Pages (GitHub, Inc.)사이트 파일 제공사이트를 여는 모든 방문자의 IP 주소 등공식 문서에 따르면 방문자 IP를 보안 목적으로 기록·저장합니다. 보유 기간은 문서에 나와 있지 않습니다.
Cloudflare Workers (Cloudflare, Inc.)사이트와 DB 사이의 API 서버글 목록 조회, 작성, 삭제 요청 전체. 글을 쓰지 않고 보기만 해도 IP 주소가 포함됩니다.Cloudflare 전 세계 네트워크에서 처리하며, 회사 정책상 주로 미국과 EEA에 저장합니다. 요청 기록(Workers Logs)을 켜면 무료 요금제는 3일, 유료 요금제는 7일 보관합니다. 이 사이트의 설정은 운영자 확인 필요입니다.
Supabase (계약 주체 Supabase Pte. Ltd., 싱가포르)글 저장 DB1번 표의 서버 쪽 정보. 방문자 IP 원문은 보내지 않습니다.DB 위치는 싱가포르 리전(ap-southeast-1)입니다. API·DB 로그는 무료 요금제에서 1일 보관합니다. 무료 요금제에는 자동 백업이 없고, 유료 요금제로 바꾸면 백업이 7일 이상 남을 수 있습니다.
jsDelivr (글꼴 Pretendard 제공)화면 글꼴 파일 제공페이지를 열 때 브라우저가 글꼴을 받으면서 IP 주소 등이 전달됩니다.정책 내용은 확인하지 못함

개인정보 보호법에 따른 처리위탁·국외이전 고지 항목(받는 자의 연락처, 이전 시기·방법, 거부 방법·절차·효과 등)이 요건을 충족하는지는 검토 전입니다. 글을 쓰지 않으면 닉네임과 본문은 전송되지 않습니다. 다만 사이트를 열기만 해도 IP 주소는 위 서비스들에 전달됩니다.

5. 삭제와 요청 방법

  • 내 글 하나: 글의 … 버튼에서 삭제합니다. 글을 쓴 브라우저에서만 됩니다.
  • 내 글 전부와 방문자 정보: 글쓰기 화면 아래의 내 글 모두 삭제를 누릅니다.
  • 브라우저 데이터를 지워 직접 삭제할 수 없거나, 다른 사람의 글에 내 개인정보가 있는 경우: 운영자에게 요청해 주세요. 연락처는 미정입니다. 요청할 때는 해당 글을 찾을 수 있는 정보(핸들 @v_…, 대략적인 작성 시각, 내용 일부)만 알려 주시면 됩니다. 신분증 같은 추가 자료는 요구하지 않습니다.
삭제로 지울 수 없는 것
  • 삭제하면 운영 DB에서는 바로 지워지지만, 삭제 전에 다른 방문자가 본 화면, 복사하거나 캡처한 내용은 지울 수 없습니다. 이미 페이지를 열어 둔 사람의 화면에서는 새로고침해야 사라집니다.
  • 4번 서비스들의 로그와 백업은 각 서비스의 보유 기간이 지나야 사라집니다.
  • DB 내부에서는 지운 데이터가 저장 공간이 재사용되기 전까지 잠시 남을 수 있습니다.

6. 그 밖의 사항

  • 처리의 법적 근거, 동의 필요 여부: 검토 전. 별도의 동의 체크박스는 두지 않았습니다.
  • 개인정보 보호책임자 또는 운영자 연락처: 미정
  • 안내 변경: 내용이 바뀌면 이 페이지에 시행일과 함께 알립니다.
